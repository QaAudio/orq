# Dashboard image gallery

Thumbnails for the README theme + UI-scale grids. Regen from `web/`:

```bash
npm run capture:readme
```

| File | Shows |
|------|--------|
| `theme-default.png` | Canvases · **default** theme |
| `theme-dracula.png` | Canvases · **dracula** |
| `theme-system.png` | Canvases · **system** (light) |
| `scale-100.png` | default theme @ **100%** zoom |
| `scale-125.png` | default theme @ **125%** zoom |
| `scale-150.png` | default theme @ **150%** zoom |

Viewport for all stills: 1440×900. Consumer loop screenshots stay in [`../usecases/`](../usecases/).
